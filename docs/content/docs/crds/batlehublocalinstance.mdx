- **API version:** `batlehub.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `bhli`
- **Guide:** [Connect a BatleHub instance](/docs/guides/connect-instance)

One BatleHub instance, owned by a namespace: its token is that
namespace's, and only the objects of that namespace use it (plus the
`BatleHubRegistry`s of the namespaces it accepts). `Ready` tells
whether the instance answers, accepts the operator's token with the
admin role and, with `external.manageConfig`, runs the configuration
rendered from this object.

While objects are bound to it, its deletion waits (`InstanceInUse`);
`batlehub.weebo.io/force-orphan: "true"` releases it and leaves them
orphaned.

## Example

```yaml
apiVersion: batlehub.weebo.io/v1alpha1
kind: BatleHubLocalInstance
metadata:
  name: my-localinstance
  namespace: team-a
spec:
  external:
    url: https://batlehub.example.com
    adminTokenSecretRef:
      name: batlehub-admin
      key: token
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `config` | `object` | no |  | BatleHub's configuration file (`config.toml`) written in YAML, key for key: a TOML table is an object, an array of tables a list of objects. Never typed here: BatleHub's own parser validates it. `${VAR}` placeholders are kept and resolved by the instance from its own environment (`managed.env`). Rendered with `managed`, or `external.manageConfig`. |
| [`configLayers`](#spec.configLayers) | `object[]` | no |  | TOML documents merged in order over `config`, the way BatleHub merges its `--config` layers (the later wins; tables merge; arrays of tables merge entry by entry on a unique `name`, else `type`). |
| [`external`](#spec.external) | `object` | no |  | A BatleHub the operator doesn't deploy: it reaches it at `url` with an admin token, observes it and, with `manageConfig`, pushes its configuration. |
| [`managed`](#spec.managed) | `object` | no |  | A BatleHub the operator deploys, in this namespace, and whose configuration it always manages. |
| [`registrySelector`](#spec.registrySelector) | `object` | no |  | Which `BatleHubRegistry`s this instance serves, rendered as `[[registries]]` entries after `configLayers`. |
| [`reload`](#spec.reload) | `object` | no |  | How a new configuration reaches the instance. |

**Rules**

- set exactly one of external and managed — `has(self.external) != has(self.managed)`
- the mode (external or managed) is immutable — `has(self.external) == has(oldSelf.external)`
