- **API version:** `batlehub.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `bhli`
- **Guide:** [Connect a BatleHub instance](/docs/guides/connect-instance)

One BatleHub instance, owned by a namespace: its token is that
namespace's, and only the objects of that namespace use it. `Ready`
tells whether the instance answers and accepts the operator's token
with the admin role.

While objects are bound to it, its deletion waits (`InstanceInUse`);
`batlehub.weebo.io/force-orphan: "true"` releases it and leaves them
orphaned.

## Example

```yaml
apiVersion: batlehub.weebo.io/v1alpha1
kind: BatleHubLocalInstance
metadata:
  name: my-localinstance
  namespace: team-a
spec:
  external:
    url: https://batlehub.example.com
    adminTokenSecretRef:
      name: batlehub-admin
      key: token
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `external` | `object` | yes |  | A BatleHub the operator doesn't deploy: it reaches it at `url` with an admin token, and observes it. (The mode where the operator deploys BatleHub itself comes in a later version.) |
